KIZASHI 12.2 — CINEMATIC OPENING ART

- Opening now uses the cinematic KIZASHI sunrise artwork exactly as the visual source.
- Removed the old generated K circle/text overlay so the artwork is not duplicated.
- Full artwork stays visible on desktop with a blurred extension behind it instead of cropping.
- Mobile uses a centered cover treatment for better screen fill.
- Opening duration: 5.6 seconds.
- Enter becomes available after 1.9 seconds; click/Enter/Space closes the opening.
- Existing SKIP area in the artwork is clickable via an invisible hit target.
- No image generation is performed by the app.
