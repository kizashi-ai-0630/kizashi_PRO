KIZASHI 9.10 — MT4 HTML Support

追加内容
- MT5などのCSV取引履歴に対応
- MT4の「詳細レポート」HTML / HTMに対応
- UTF-8 / Shift_JIS / Windows-1252を自動判定
- MT4レポートから決済済みbuy/sellのみ抽出
- 損益は Profit + Commission + Swap + Taxes の合計で集計
- 入出金・残高調整・集計行を分析対象外に設定
- ファイル選択画面とサイドバーを「取引履歴」に統一

MT4からの保存方法
1. MT4下部の「ターミナル」→「口座履歴」を開く
2. 履歴一覧を右クリックし、期間を選ぶ（全履歴でも可）
3. もう一度右クリックして「詳細レポートの保存」を選ぶ
4. 保存された .html または .htm をKIZASHIへ読み込む

対応ファイル
- .csv
- .html
- .htm
最大サイズ: 12MB
