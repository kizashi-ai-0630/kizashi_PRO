KIZASHI PRO 9.13 API GUIDE BETA

追加内容
- 管理画面に「APIキーを取得する」「取得方法と料金を見る」を追加
- OpenAI APIキーの用途、料金、取得手順、安全な取り扱いをモーダルで案内
- APIキーなしでも分析・Guardian・記録・成長・CSV/MT4 HTML読込を利用できることを明示
- API Keys / Billing のOpenAI公式画面への導線を追加
- ESCキー、背景クリック、閉じるボタンでモーダルを閉じられるように対応
- スマホ表示にも対応

料金に関する注意
- ChatGPTの契約とAPI料金は別です。
- OpenAIのプリペイド最低購入額は現在5ドルですが、仕様はOpenAI側で変更される場合があります。
- 利用者にはOpenAI側の利用上限と自動チャージ設定の確認を推奨します。
